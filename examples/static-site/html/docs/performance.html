Performance Tuning

Every knob that matters — from kernel to container.

Kernel (sysctl)

Place this file at /etc/sysctl.d/99-gateway.conf and run sudo sysctl --system to apply.

# TCP connection handling
net.core.somaxconn = 65535
net.ipv4.tcp_max_syn_backlog = 65535
net.ipv4.tcp_tw_reuse = 1
net.ipv4.tcp_fin_timeout = 15
net.ipv4.ip_local_port_range = 1024 65535

# Enable IP forwarding (required for WireGuard)
net.ipv4.ip_forward = 1

# SYN flood protection
net.ipv4.tcp_syncookies = 1

# Memory & file handles
fs.file-max = 2097152
fs.inotify.max_user_watches = 524288
vm.swappiness = 10
vm.max_map_count = 262144
SettingWhy
somaxconn = 65535Max connection queue. Default 4096 saturates under moderate load.
tcp_tw_reuse = 1Reuse TIME_WAIT sockets for new outbound connections. Safe on a relay.
tcp_fin_timeout = 15Free sockets faster. Default 60s wastes resources on a relay.
vm.swappiness = 10Strongly prefer RAM. VPS RAM is fast; swap is usually a slow network disk.
vm.max_map_count = 262144Required by JVM-based apps (Elasticsearch, etc).

Docker Daemon

Save as /etc/docker/daemon.json, then sudo systemctl restart docker.

{
  "storage-driver": "overlay2",
  "log-driver": "local",
  "log-opts": {
    "max-size": "10m",
    "max-file": "3",
    "compress": "true"
  },
  "icc": false,
  "no-new-privileges": true,
  "live-restore": true,
  "userland-proxy": false,
  "exec-opts": ["native.cgroupdriver=systemd"],
  "features": { "buildkit": true }
}
FlagEffect
log-driver: localBinary format, compressed. ~3× less disk than json-file.
userland-proxy: falseUses kernel iptables DNAT instead of a Go process per port.
live-restore: trueContainers stay running during dockerd restarts/upgrades.
icc: falseContainers can't reach each other unless on a shared named network.

Nginx

# Gzip — add to nginx.conf
gzip on;
gzip_types text/plain text/css application/json
  application/javascript text/xml image/svg+xml;
gzip_min_length 1024;
gzip_vary on;

# Cache static assets 1 year
location ~* \.(js|css|png|jpg|ico|svg|woff2)$ {
  expires 1y;
  add_header Cache-Control "public, immutable";
  access_log off;
}

# SPA fallback (React/Vue/Svelte)
location / {
  try_files $uri $uri/ /index.html;
}
💡 Immutable caching Use content-hashed filenames (e.g. app.abc123.js) with Cache-Control: public, immutable. Browsers will never re-request the file — they cache it forever. Your build tool (Vite, webpack) does this automatically.

Gunicorn Worker Sizing

import multiprocessing

# Rule of thumb: (2 × CPUs) + 1
workers = multiprocessing.cpu_count() * 2 + 1

# CPU-bound workload (ML, data processing)
worker_class = "sync"

# IO-bound (many DB/API calls)

# Mixed
# worker_class = "gthread"  # set threads=4

timeout = 30

WireGuard Throughput

  • Enable net.ipv4.ip_forward = 1 — required for tunnel routing.
  • Use kernel WireGuard (wireguard kernel module), not userspace — kernel module is 3–5× faster.
  • MTU: set MTU = 1420 in the WireGuard [Interface] to avoid fragmentation inside tunnels.
  • On the VPS, PersistentKeepalive is not needed — only on the home server (the NAT client).
