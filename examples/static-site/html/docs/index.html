Overview

The CGNAT Gateway lets you expose services running on your home server to the internet — even if your ISP assigns you a shared IP (CGNAT) with no port forwarding available.

The architecture uses a cheap VPS as a public relay. Your home server connects to the VPS via a WireGuard tunnel (outbound only, no open ports needed). Traffic is forwarded through socat and routed by Traefik, with Cloudflare in front for TLS and WAF.

Requirements

  • A Linux VPS (Ubuntu 22.04+ recommended) — even a €3/mo works
  • A domain name with DNS managed by Cloudflare (free plan is fine)
  • A home server running Docker (any Linux distro)
  • Basic familiarity with SSH and the command line
