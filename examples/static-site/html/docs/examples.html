Examples

Copy-paste ready Dockge stacks. No Dockerfile needed — all use prebuilt images.

💡 Dockge tip Each stack lives in /opt/stacks/<name>/. Copy the files there, then hit Deploy in Dockge.

Web Hosting

🌐
Static Site
:8080
Nginx serving HTML/CSS/JS. Gzip, 1-year asset caching, SPA fallback. This very site.
volumes:
  - ./html:/usr/share/nginx/html:ro
  - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro

APIs

🐍
Python Flask + Gunicorn
:5000
Mount app.py + gunicorn.conf.py. Deps installed automatically via pip install in the command. Pip cache persisted as named volume.
image: python:3.12-slim
command: >
  sh -c "pip install flask gunicorn
         && gunicorn -c gunicorn.conf.py app:app"
🟢
Node.js + Express
:3000
Mount app.js. node_modules persisted as named volume. Runs as non-root node user.
image: node:22-alpine
command: >
  sh -c "npm install express
         && node app.js"
🔴
Flask + Redis
:5001
Multi-container. Redis is password-protected and network-isolated. Hit counter + key/value CRUD.
REDIS_HOST=redis
REDIS_PASSWORD=changeme
# Change the password!

Self-Hosted Tools

📊
Uptime Kuma
:3001
Uptime monitoring + public status page. Telegram, Discord, email alerts. No extra files needed.
image: louislam/uptime-kuma:latest
volumes:
  - uptime-kuma-data:/app/data
📂
File Browser
:8070
Web file manager — browse, upload, download via HTTPS. Change the default admin/admin immediately.
image: filebrowser/filebrowser:latest
volumes:
  - ./data:/srv
  - filebrowser-db:/database
📡
Reverse Proxy
any
socat only — no app container. Forward to any LAN host: Home Assistant, Proxmox, cameras, NAS.
image: alpine/socat:latest
command: TCP4-LISTEN:8123,bind=10.8.0.2,
         fork,reuseaddr TCP4:192.168.1.10:8123

Game Servers

📌 DNS note Game servers bypass Cloudflare — set the DNS record to DNS only (grey cloud). TCP for Minecraft, UDP for CS2/Valheim.
🎮
Minecraft (TCP)
:25565
command: TCP4-LISTEN:25565,fork,reuseaddr
         TCP4:10.8.0.2:25565
ports:
  - "25565:25565"
🔫
CS2 / Valheim (UDP)
:27015
command: UDP4-LISTEN:27015,fork,reuseaddr
         UDP4:10.8.0.2:27015
ports:
  - "27015:27015/udp"
