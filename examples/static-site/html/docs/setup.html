Setup Guide

From a fresh VPS to a production HTTPS gateway.

⚠️ Before you start Keep a second SSH session open when applying changes — some steps restart sshd or change the SSH port.

1 — VPS System Prep

Update the system and install base dependencies. Do not use apt install docker.io — it is outdated.

sudo apt update && sudo apt upgrade -y
sudo apt install -y wireguard wireguard-tools curl ufw \
  fail2ban unattended-upgrades ca-certificates

2 — Install Docker Engine

Use Docker's official repository:

sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg \
  -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

sudo tee /etc/apt/sources.list.d/docker.sources <
sudo docker run hello-world
docker compose version

3 — WireGuard on the VPS

The VPS is the WireGuard server. It listens on UDP :51820.

cd /etc/wireguard
wg genkey | sudo tee privatekey | wg pubkey | sudo tee publickey
sudo chmod 600 privatekey
wg genpsk | sudo tee preshared.key && sudo chmod 600 preshared.key

Create /etc/wireguard/wg0.conf:

[Interface]
PrivateKey = <VPS_PRIVATE_KEY>
Address = 10.8.0.1/24
ListenPort = 51820
PostUp   = iptables -A FORWARD -i wg0 -j ACCEPT; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
PostDown = iptables -D FORWARD -i wg0 -j ACCEPT; iptables -t nat -D POSTROUTING -o eth0 -j MASQUERADE

[Peer]
PublicKey = <HOME_PUBLIC_KEY>
PresharedKey = <PRESHARED_KEY>
AllowedIPs = 10.8.0.2/32
sudo wg-quick up wg0
sudo systemctl enable wg-quick@wg0

4 — WireGuard on the Home Server

🔴 Critical for CGNAT PersistentKeepalive = 25 is mandatory. Without it, the CGNAT NAT mapping expires every ~60–120s and the tunnel silently drops. 
[Interface]
PrivateKey = <HOME_PRIVATE_KEY>
Address = 10.8.0.2/24

[Peer]
PublicKey = <VPS_PUBLIC_KEY>
PresharedKey = <PRESHARED_KEY>
Endpoint = <VPS_IP>:51820
AllowedIPs = 10.8.0.1/32
PersistentKeepalive = 25
# Test: from VPS, ping home server
ping 10.8.0.2

6 — Deploy Traefik on VPS

Deploy from cgnat/vps/. Traefik handles HTTPS termination and routing to socat containers on the proxy network.

cd cgnat/vps
docker compose up -d

# Check Traefik is up
docker logs traefik --tail 20

7 — Add a Service (Pattern)

Every service follows the same 4-step pattern:

  1. Home server: app container + socat binding on 10.8.0.2:<port>
  2. VPS: socat on the proxy network forwarding to 10.8.0.2:<port>
  3. VPS: Traefik router + service entry in dynamic.yml
  4. Cloudflare: A record (proxied) pointing to VPS IP
# dynamic.yml snippet
http:
  routers:
    myservice:
      rule: "Host(`service.example.com`)"
      entryPoints: [websecure]
      service: myservice
      tls:
        options: modern
      middlewares: [security-headers, rate-limit]
  services:
    myservice:
      loadBalancer:
        servers:
          - url: "http://socat-myservice:8080"
