# svelte-runes-playground

Svelte 5 playground to show off the new Runes API, SvelteKit remote functions, server data, and modern Svelte primitives.

This is intentionally minimal but hits the "new hyped features" without screenshots.

## Stack

- Svelte 5 (runes)
- SvelteKit
- TypeScript

## Quick start

```bash
cd cgnat/examples/svelte-runes-playground
npm install
npm run dev
```

You can wire it into CGNAT (like `vui-blog`) later if you want to expose it publicly.
